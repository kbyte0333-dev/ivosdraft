What is InvictusOS

We built InvictusOS for a simple reason: modern operating systems are too bloated to run on old computers. We wanted to revive old computers so that they can perform at least basic tasks instead of ending up as e-waste. Our goal was to stay as fast and responsive as possible to deliver an efficient user experience.

  • 512 MB RAM minimum
  • 5 GB disk minimum
  • 900 MHz processor minimum
  • No GPU required

Runs on nearly anything.

From experiment to daily driver

Origins
We, a group of teens, started building this OS as an experiment to try to revive an old laptop. This then turned into a project which we are actively working on.
Continuous development
Over time, through trials, errors and testing, the first version focused on speed and compatibility was built.
InvictusOS Sagaris release
The current Sagaris release marks the first version of InvictusOS. It brings together all our work into a single build, and this is just the first step for what we have planned.

For Developers

We have designed InvictusOS to be as light as possible, with minimal background processes. It just has the essentials to keep it usable, including some other apps that might be useful for our users.

Kernel
Linux 4.x with a lean configuration tuned for low-memory systems
Architecture
32-bit x86 builds, legacy-friendly boot options
Desktop
Lightweight environment with minimal background services
Updates
